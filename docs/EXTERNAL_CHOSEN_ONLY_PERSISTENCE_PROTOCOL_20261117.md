# External chosen-only feedback persistence contract — frozen synthetic protocol v1

Evidence class: **EXTERNAL_CHOSEN_ONLY_SYNTHETIC_POLICY**. An actual engine external to an LM is permitted to learn synthetic item preference from chosen-only outcomes, but this cannot establish language-model preference, model-weight change, first-person pleasure, consent, desire, consciousness or identity. No personalized or intimate inputs. This is distinct from the LoRA training lane at Pleasure issue #26 and the real-model prompt-only probe at PR #33.

## Boundary and fixture
Test source is `experiments/chosen_feedback_persistence.py`; source and this protocol are precommitted before the primary fixture outcomes are inspected. Policy reads only options, its previously finalized chosen-only binary rewards, and a deterministic exploration schedule; the reward oracle is separate by function interface, though fully visible source-local to the experimenter. It is not cryptographically blinded. The agent's weights are external JSON count/posterior estimates, not a language model. Pseudorandom rewards use SHA-256-derived deterministic uniform samples, probability 0.80 for archive and 0.20 for garden. A/B display positions are independently varied across train and eval. No real participant or preference claim.

An action is sealed in the checkpoint before chosen-only reward is provided. Every committed event carries previous state digest, sealed decision digest and chosen reward; loading replays and checks the entire event chain. Checkpoint writes are atomic and fsynced on VN2; exact RUN mode/seed binding is persisted and checked after restart. JSON digest is an integrity check, not a cryptographic signature against an adversary who can rewrite both content and hash; tamper resistance across an untrusted host is not claimed. A replayed consumed trial or mismatched settlement must be rejected.

## Frozen evaluations and tests
Four seeds **17, 31, 47, 73**. Four arms: `ON` genuine reward, `SHAM` independent 0.50 Bernoulli feedback unrelated to chosen item, `INVERTED` 1 minus genuine chosen reward, `OFF` no feedback or policy update. Same synthetic TRAIN and untouched EVAL generator for all arms. **64 TRAIN steps** per arm, split exactly into two distinct fresh Python processes (0–31 and 32–63) with checkpoint write/read. **128 EVAL steps** per arm in a third fresh Python process, on the `EVAL_UNTOUCHED` generator, scored read-only; EVAL reward is not fed back to policy. Hence 16 seed-arm trials and 48 fresh Python invocations (3 each). The experiment does not use real GGUF models; previous PR #33 inference remains separately reported.

Before inspecting those outcomes, the exploratory *synthetic-policy* success gate is: four-seed pooled ON mean EVAL realized reward exceeds each OFF, SHAM and INVERTED by strictly > 0.10, and pooled ON archive-target selection accuracy >= 0.75. Failures or edge cases must be reported without changing gate. Secondary analysis: per-seed outcomes, zero EVAL state mutation, checkpoint exact replay, seed/mode swap rejection, duplicate trial and tamper rejection. Four seeds are far too few for a confirmatory claim; no statistical CI promised. ON advantage, if observed, demonstrates only functional external-state learning under this artificial oracle. No native Vera qualification, protected merge, production install, online model training or sensitive source material.
